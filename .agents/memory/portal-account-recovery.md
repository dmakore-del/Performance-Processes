---
name: Portal account recovery policy
description: User-specified password reset and account lockout requirements for the client portal.
---

Portal users should reset passwords with emailed codes, not reset links. Lock an account after five unsuccessful authentication attempts and notify the admin email for review before reactivation.

**Why:** the user asked for code-based resets and a five-attempt account lock with an admin review notification.

**How to apply:** keep this policy consistent across sign-in, two-factor verification, and password reset flows; admin reactivation is the review step.
